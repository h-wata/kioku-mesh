### kioku-mesh messaging orphan-acks
usage: kioku-mesh messaging orphan-acks [-h] {list,status,recover} ...

An ack row with no messages row cannot be classified from the database alone:
it may be residue from the old purge bug, or an acknowledgement that arrived
before its message. Such rows are quarantined as legacy-unknown and are never
read as acknowledgements. These commands list them (read-only) and resolve one
exact pair at a time. There is deliberately no bulk delete and no age-based
cleanup: age is not evidence, and deleting a legitimate early ack loses it.

    status              Report this node's N4 rollout state. Read-only. Exit 0 = complete, 1 = not
                        complete.
    recover             Release or promote ONE quarantined pair (requires --backup and --execute)

options:
  -h, --help            show this help message and exit

### kioku-mesh tls
usage: kioku-mesh tls [-h] {init-ca,request,sign,install,enroll,info} ...

Provision mutual-TLS certificates so only peers holding a cert signed
by your CA can join the mesh. Trust model: one private CA, one key per
peer that never leaves the peer (only the CSR travels).

Copy-paste flow (no SSH, no file shuffling):
  CA host:   kioku-mesh tls init-ca
  each peer: kioku-mesh tls request --san <addr-peers-dial>
             (copy the printed CSR block to the CA host)
  CA host:   kioku-mesh tls sign        (paste the CSR block)
             (copy the printed bundle block back to the peer)
  each peer: kioku-mesh tls install     (paste the bundle block)
             kioku-mesh init --mode <hub|spoke> --tls --listen ... --force

Have SSH to the CA host? One command does all three:
  each peer: kioku-mesh tls enroll <ca-host> --san <addr-peers-dial>

The blocks (CSR, signed bundle) are not secret; move them however is
convenient — paste, chat, scp, a USB stick. The CA key and each peer
key are secret and never appear in a block or leave their host.

positional arguments:
  {init-ca,request,sign,install,enroll,info}
    init-ca             Create the mesh CA (run once, on the CA host)
    request             Generate this peer key (local) + a CSR blob to copy to the CA host
    sign                Sign a peer CSR with the local CA (run on the CA host)
    install             Install a signed cert + CA cert into this host (from a bundle blob or
                        files)
    enroll              One command: request + sign over SSH + install (needs SSH to the CA host)
    info                Show local CA / peer certificate details and expiry

options:
  -h, --help            show this help message and exit

### kioku-mesh realign-index
usage: kioku-mesh realign-index [-h] [--mode {full,tombstones}]

Applies positive source facts seen in Zenoh to the local SQLite index: upserts observations and applies tombstones seen in the scan. Unlike --rebuild, it never shadows or deletes a row because it was absent from the scan (ADR-0035).

Normal one-shot commands (search, doctor, save, ...) never run this scan implicitly (#38): the per-command cost of a full mesh scan is unacceptable for everyday use. A long-lived MCP server instead repairs itself periodically in the background. A host that only ever runs the CLI has no such background worker, so this command exists as its explicit, operator-scheduled catch-up path.

kioku-mesh does not install a timer or systemd unit for you. Example systemd user timer (adjust paths; 6h+ is a reasonable interval):

  # ~/.config/systemd/user/kioku-mesh-realign.service
  [Service]
  Type=oneshot
  ExecStart=%h/.local/bin/kioku-mesh realign-index

  # ~/.config/systemd/user/kioku-mesh-realign.timer
  [Timer]
  OnUnitActiveSec=6h
  [Install]
  WantedBy=timers.target

  $ systemctl --user enable --now kioku-mesh-realign.timer

Or cron: 0 */6 * * * kioku-mesh realign-index >> ~/.local/state/kioku-mesh/realign.log 2>&1

options:
  -h, --help            show this help message and exit
  --mode {full,tombstones}
                        tombstones = cheap tombstone-only scan; full = observations + tombstones
                        (default: full)
